# project-research-architect

一个面向所有软件项目的研究优先型规划 Skill。

它要求模型在开始开发前澄清需求、通过 GitHub MCP 调研成熟项目、比较复用路径和技术路线，并以阶段确认的方式推进实施。同时，它建立按需检索的项目上下文文档，避免模型默认读取整个项目造成上下文浪费。

## 包含内容

- `SKILL.md`：触发条件与主工作流
- `references/`：评估标准和阶段门规则
- `scripts/`：结构验证与打包辅助
- `evals/`：初始测试用例

## 使用原则

该 Skill 不绑定 Web 技术栈。是否需要 UI、前后端拆分或部署方案，由具体项目需求决定。
